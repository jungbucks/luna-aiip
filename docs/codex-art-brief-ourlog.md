# 작업: 교육용 웹게임 「런칭! 나의 첫 AI 아이돌」의 가상 SNS 'ourlog' 게시물 그림 16장

## 배경
고등학생용 지식재산권 교육 게임이다. 학생은 AI 버추얼 아이돌 회사 대표가 된다.
매 에피소드가 끝나면 게임 속 가상 SNS 'ourlog'에 아이돌 공식 계정 게시물이 올라온다.
학생의 선택(정답·오답)에 따라 팬 반응이 달라진다.
네가 그릴 것은 그 게시물 사진이다. 지식재산권을 가르치는 게임이므로,
그림 자체가 남의 권리를 침해하면 안 된다(아래 '금지'를 반드시 지킬 것).

## 캐릭터 (기존 그림과 같은 얼굴·그림체로)
참조 그림(이 그림과 같은 인물로 보여야 한다):
- assets/characters/sol-neutral.png, sol-happy.png   (솔)
- assets/characters/luna-neutral.png, luna-happy.png (루나)

- 솔(SOL): 태양 컨셉 보이 아이돌. 다크 인디고 투블럭 머리, 해 모양 머리핀, 재킷.
- 루나(LUNA): 달빛 컨셉 걸 아이돌. 보라→청록으로 물드는 긴 머리, 달 모양 머리핀, 무대 의상.
- 그림체: 참조 PNG와 같은 애니메이션풍 일러스트. 실사·3D 렌더 금지.
- 두 캐릭터 모두 창작 인물이다. 어떤 실존 연예인도 닮지 않게 그린다.

## 그릴 장면 (8장면 × 솔·루나 = 16장)
| 키 | 장면 |
|---|---|
| ep1 | 데뷔곡 공개 날. 작은 녹음실 문 앞에서 헤드폰을 목에 건 채 찍은 첫 셀카 느낌 |
| ep2 | 작은 무대 위 립싱크 기술 시연. 뒤 화면에 음파·입 모양 그래픽(글자 없음) |
| ep3 | 새 공식 로고 공개. 아이돌 옆 벽면에 지어낸 도형 마크(해 또는 달을 단순화한 기호, 글자 없음) |
| ep4 | 컵라면과 노트북이 있는 좁은 원룸 사무실. 아이돌 화면을 띄운 모니터 앞에서 팀이 새 노래를 준비하는 장면(팀원은 뒷모습·손만) |
| ep5 | 팬미팅 단체 사진. 아이돌 뒤로 팬 6~8명의 얼굴이 또렷하게 보인다(팬은 모두 창작 인물) |
| ep5-blur | ep5와 같은 구도. 팬 얼굴만 귀여운 해·달·별 스티커로 가렸다 |
| ep6 | 가상의 음료 광고 사진. 아이돌이 원래 모습 그대로 캔 음료를 든다. 캔에는 지어낸 무늬만, 브랜드 글자 없음 |
| ep6-k | ep6와 같은 광고. 아이돌이 '유명 배우풍'으로 꾸며졌다(선글라스, 넘긴 머리, 정장 등). 특정 실존 배우를 떠올리게 하는 얼굴·머리·의상 조합은 금지 — 일반적인 '스타 화보' 분위기만 |

ep5/ep5-blur, ep6/ep6-k는 짝이다. 두 장을 나란히 놓았을 때 차이(얼굴 가림, 광고 콘셉트)만 달라 보이게 구도·조명·배경을 맞춘다.

## 금지
- 실존 인물·실존 연예인·실존 배우를 닮은 얼굴 (팬·팀원 포함)
- 실존 회사 로고·브랜드명·상표·제품 디자인
- 인스타그램 등 실제 SNS 화면 요소: 하트/말풍선/종이비행기 아이콘, 그라데이션 카메라 로고, 스토리 고리, 좋아요 숫자, 계정 이름 표시줄
- 실제 휴대폰 UI 요소(노치·다이내믹 아일랜드, 상태바)
- 그림 속 글자. 꼭 필요하면 의미 없는 짧은 지어낸 글자만 (게임이 위에 계정명·캡션을 따로 얹는다)
- 학생용이므로 노출·폭력·음주 표현 금지 (ep6 음료는 탄산음료/주스류)

## 규격
- 정사각형 1080×1080 이하 (1080 권장)
- WebP, 장당 150KB 이하, 16장 합계 2.5MB 이하
- 사진처럼 꽉 찬 장면(투명 배경 아님). 가장자리 4% 안에는 중요한 요소를 두지 않는다(둥근 모서리로 잘림)
- 다크·라이트 두 모드에서 모두 보이니 화면 전체가 지나치게 어둡거나 하얗지 않게

## 납품
- 경로(저장소 루트 기준):
  assets/ourlog/sol/ep1.webp … ep6-k.webp
  assets/ourlog/luna/ep1.webp … ep6-k.webp
  파일 이름은 위 '키'와 정확히 같게 (ep1, ep2, ep3, ep4, ep5, ep5-blur, ep6, ep6-k)
- assets/ourlog/manifest.json: 파일마다 {path, width, height, bytes}
- assets/ourlog/preview.png: 16장을 4×4로 모은 확인용 시트(배포에 안 쓰는 확인용, 1MB 이하)
- 코드(js/·data/·css/)는 건드리지 않는다. 연결(ART_READY 스위치)은 게임 쪽에서 한다.

## 자체 확인 (납품 전)
- 16개 파일 이름·경로가 정확한가
- 장당 150KB 이하, 합계 2.5MB 이하인가 (manifest의 bytes로)
- 솔·루나가 참조 PNG와 같은 인물로 보이는가
- 금지 목록의 어느 것도 없는가 — 특히 ep6-k가 특정 배우를 떠올리게 하지 않는가
