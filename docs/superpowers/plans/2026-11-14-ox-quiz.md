# 에피소드 확인 O/X 퀴즈 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 에피소드 결정 뒤 정산 직전에 '다른 상황에 적용하는' O/X 한 문제(틀리면 하나 더)를 내고, 엔딩 리포트에 두 번 다 놓친 개념을 모아 보여 준다 — 스탯·배지·엔딩과 무관.

**Architecture:** 문항은 `data/quiz.js`, 판정·기록·목록은 DOM 없는 `js/quiz.js`(node 검산), 흐름은 `js/main.js`가 `bridge()` 앞에 끼운다. `js/engine.js`는 건드리지 않는다. 화면은 기존 팝업(`showPopup`)과 엔딩 리포트(`ending.js`)를 쓴다.

**Tech Stack:** 바닐라 ES 모듈(빌드 없음, HTTP 전용) · `node test/verify.mjs` · `test/probe.html`(같은 오리진 헤드리스 Edge).

**Spec:** `docs/superpowers/specs/2026-11-14-ox-quiz-design.md`

## Global Constraints

- 💰·📈·🛡 스탯, 배지, 엔딩 판정에 영향 없음. `js/engine.js` 변경 금지. 저장 키 `luna_save_v1`·`schemaVersion` 그대로(필드 추가만).
- 문항·해설 = 설계 문서 표 그대로(뜻을 바꾸면 표도 같이). 이름 토큰·캐릭터 이름 없음. SPEC §10 가드레일(저작권 "무조건 불법" 금지, 퍼블리시티권 "법으로 보호받는 재산적 이익" 수준).
- 본문 15px 이상, `prefers-reduced-motion` 존중(기존 팝업 그대로 쓰면 충족).
- 화면 문구(정함): 문제 팝업 제목 "개념 확인 O/X", 버튼 "⭕ 맞아요"·"❌ 아니에요", 결과 제목 "맞았어요!"·"아쉬워요", 정답 표시 "정답: O"/"정답: X", 버튼 "비슷한 문제 하나 더 →"·"계속 →", 엔딩 소제목 "개념 확인 O/X에서 두 번 다 놓친 개념".
- 커밋은 로컬만(GitHub 계정 정지 — push·Pages 금지). 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. 오답 → [대가를 치르고 진행]에서 집행유예 법정(최종 아님)을 거쳐 계속하는 길 — 퀴즈가 한 번만 나오고 정산으로 간다. → Task 2 프로브 `quiz-after-court`.
2. 최종 법정(게임 오버)으로 끝나는 길 — 퀴즈 없이 엔딩, 그 EP는 목록에 없음. → Task 1 verify `missed-excludes-unplayed` + Task 2 프로브.
3. 옛 저장(`G.quiz` 없음) 이어 하기 → 엔딩 목록 비어 있고 오류 없음. → Task 1 verify `missed-old-save`.
4. 결과 팝업 버튼 연타·Enter 반복 — 둘째 문제가 두 번 뜨거나 정산이 두 번 되지 않는다. → Task 2 프로브 `quiz-no-double`.
5. 엔딩: 선택은 다 맞혔는데 퀴즈만 놓친 경우 — "틀린 개념이 없습니다" 문구가 퀴즈 목록과 같이 나오지 않는다. → Task 2 프로브 `ending-clean-vs-quiz`.

### Task 1: 문항 데이터 + 퀴즈 로직(node 검산)

**Files:**
- Create: `data/quiz.js`, `js/quiz.js`
- Modify: `test/verify.mjs` (맨 끝 집계 앞에 '[O/X 퀴즈]' 절)

**Interfaces:**
- Produces: `data/quiz.js` → `export const QUIZ = { 1: { main: { q, a, exp }, more: { q, a, exp } }, …, 6: {…} }` (`q`·`exp` 문자열, `a` 불리언 — true = O)
- Produces: `js/quiz.js` →
  - `export function resultOf(firstCorrect: boolean, secondCorrect?: boolean): 'ok' | 'more-ok' | 'missed'`
  - `export function record(state, ep: number, result): void` — `state.quiz`가 없으면 `{}`로 만들고 `state.quiz[ep] = result`(덮어씀)
  - `export function missedEps(state): number[]` — `result === 'missed'`인 EP 번호 오름차순, `state.quiz` 없으면 `[]`

  - `quiz-answers`: 본 문제 답 = `[false,false,false,true,true,false]`(EP1~6), 하나 더 = `[false,true,true,false,true,true]`(설계 표 그대로)
