# AI 지재권 쟁점 도감 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans 또는 subagent-driven-development. 스펙: `docs/superpowers/specs/2026-07-18-ip-dogam-design.md`.

**Goal:** 루나 게임 자매 페이지 `dogam.html` — 리서치 기반 지재권 쟁점 12장(양측 대립·상태 배지·실제 사례·더보기), 게임 엔딩에 티저 링크.

**Architecture:** 바닐라 ES 모듈(빌드 없음, 게임과 동일). `data/issues.js`(콘텐츠) ↔ `js/dogam/render.js`(렌더) ↔ `js/dogam/main.js`(필터·이벤트). 게임 팔레트 변수 공유(css/dogam.css). 게임 코어 무변경, ending.js에 링크 1줄만.

## Global Constraints

- 바닐라 ES 모듈, 빌드 없음. 게임 CSS 변수 재사용(--bg #0f1220 등, css/dogam.css는 자체 :root 없이 style.css 톤 승계 목적의 값 복제 허용).
- 본문 15px 이상(게임 규칙). reduced-motion 존중.
- 미결 사건 확정 서술 금지 — status 배지로 표시, verify가 금칙어 차단.
- 사례·법리는 §8 검증표 = 교사 검수 관문. **검수 전 배포 금지**를 CLAUDE.md·하단 고지에 명시.
- 커밋 끝에 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- 프로브는 게임과 같은 오리진에서 서빙(file:// + http iframe 크로스오리진 주의 — CLAUDE.md §2).
