# ourlog 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 루나폰에 가상 SNS 앱 ourlog를 더한다. EP마다 수첩 적기 뒤 알림을 띄우고, 선택(정답·오답·다시 선택)에 따라 다른 팬 반응을 실시간처럼 보여 준다.

**Architecture:** 계산은 DOM 없는 `js/ourlog-feed.js`에 둔다(verify가 Node에서 검산). 글은 `data/ourlog.js`, 화면은 `js/ui/ourlog.js`와 `css/ourlog.css`에 둔다. 루나폰의 네 번째 앱 층 `#appOurlog`는 `phone.js` 틀(LAYER·DOCK·뒤로 가기·inert)에 끼운다. `main.js`는 수첩 적기와 정산 사이에 단계 하나를 넣는다. 반응 갈래는 그 EP 배지에서 나오므로 저장 구조는 바꾸지 않는다.

**Tech Stack:** 바닐라 ES 모듈, 빌드 없음. 검증은 `node test/verify.mjs`와 `node test/run-probe.mjs`(헤드리스 Edge)로 한다.

**Spec:** `docs/superpowers/specs/2026-11-20-ourlog-design.md`(승인 2026-11-20). 프로젝트 규칙은 `CLAUDE.md`, `SPEC.md`에 있다.

## Global Constraints

- `engine.js`·점수·배지·엔딩 판정·저장 칸(`state.js checkSave`)은 바꾸지 않는다.
- 갈래 매핑: 배지 `'full'`→`right`, `'half'`→`half`, `'none'`→`wrong`, `null`→게시물 없음.
- 좋아요 배율 `likes.live`·`likes.later`
  - 6편 모두 `live.wrong > live.right` 이고 `later.wrong < later.right`
  - 초안 값: live `{right:1.0, half:0.9, wrong:1.3}`, later `{right:1.0, half:0.9, wrong:0.6}`
- 댓글
  - 편·갈래마다 8~10개(half는 끼워 넣은 뒤)
  - 한 줄 40자 이하
  - verify `SLANG` 금지, 욕설·조롱 없음
  - 아이디는 지어낸 영문 소문자 `/^[a-z0-9_.]{3,20}$/`이고, 한 편 안에서 겹치지 않음
  - 실존 인물·브랜드 없음
- 이름은 토큰만 쓴다(`{n}`·`{N}`·받침 조사). 계정은 `{N}_official`이다. 렌더는 `esc()`/`T()` 통로를 거친다.
- 화면에 넣는 숫자는 정수로 만든 글자다(`chat.js num()` 또는 그와 같은 정수 검사).
- 인스타그램을 본뜨지 않는다. 그라데이션 카메라 로고, 같은 모양의 하트·말풍선·공유 아이콘, 스토리 고리를 쓰지 않는다. 로고는 `ourlog` 글자뿐(악센트 색)이다.
- 앱 바탕은 불투명 `--app-bg`이고 흐림 효과는 없다. 새 층은 `#app`의 자손이다. 다크·라이트 대비는 4.5:1이다.
- 실시간 연출
  - 댓글은 약 0.7초 간격으로 나오고, 누르면 남은 댓글이 다 나온다.
  - `prefers-reduced-motion`이면 처음부터 다 나온 상태다.
  - 알림을 열지 않으면 추가 시간은 0초다.
- 그림
  - 경로는 `assets/ourlog/<sol|luna>/<key>.webp`이고, 정사각형 1080px 이하, 장당 150KB 이하, 합계 2.5MB 이하다.
  - 16장이다. 키는 `ep1 ep2 ep3 ep4 ep5 ep5-blur ep6 ep6-k`.
- 문구는 모두 `data/strings.js`(ui.ourlog)와 `data/ourlog.js`에만 둔다. 둘 다 교사 검수 대기로 표시한다.

## Review Focus

1. **ourlog를 연 채로 브라우저·폰의 뒤로 가기를 누른다.** 앱이 닫히고 정산이 정확히 한 번 와야 한다(💰 +10 한 번).
2. **[ourlog 열기]·[넘어가기]를 연타한다.** 정산이 한 번만 와야 한다.
3. **실시간 재생 도중 닫는다.** 닫힌 뒤에는 타이머가 남아 댓글을 붙이거나 오류를 내면 안 된다. 홈 아이콘으로 다시 열면 그 게시물은 댓글이 다 나온 정지 상태여야 한다.
4. **알림 카드가 떠 있는 동안 뒤를 누른다.** 뒤 화면(메신저·홈 아이콘·독)이 눌리면 안 되고, Tab은 카드 안에서만 돌아야 한다.
5. **재생 중 새로 고침 → 이어 하기.** EP 시작 상태로 돌아가야 한다. 피드에는 배지가 있는 EP 게시물만 있고, 지금 EP 게시물은 없어야 한다. 중복도 없어야 한다.

각 줄의 검사는 Task 3·4의 프로브 단계에 들어 있다.

### Task 1: 피드 계산 모듈 + 데이터 틀(EP1 글)

**Files:**
- Create: `js/ourlog-feed.js`, `data/ourlog.js`
- Test: `test/verify.mjs`(새 절 `[ourlog]`)

**Interfaces:**
- Produces (`js/ourlog-feed.js`, DOM 없음):
  - `variantOf(badge) -> 'right'|'half'|'wrong'|null`
  - `commentsFor(post, variant) -> Array<{who, text}>`
    - right·wrong은 그 목록 그대로다.
    - half는 right 목록에 `post.comments.half`의 각 `{at, who, text}`를 `at` 위치에 끼운 새 배열이다(원본을 바꾸지 않음).
  - `imageKey(post, variant) -> string`: half는 right 그림을 쓴다.
  - `followersFor(fame:int) -> int`: 📈 0~100에서 단조 증가한다.
  - `likesFor(post, variant, fame:int, mode:'live'|'later') -> int`: `followersFor(fame)`과 `post.likes[mode][variant]`에 비례하는 정수다. 식은 구현자가 정한다.
  - `feedOf(state) -> Array<{ep:int, variant}>`: 배지가 `null`이 아닌 EP만, 최신(큰 ep) 먼저.
  - `fmtCount(n:int) -> string`: 1만 미만은 `1,234`, 1만 이상은 `2.4만`(소수 한 자리, `.0` 생략).
- Produces (`data/ourlog.js`):
  - `export const ART_READY = false`
  - `export const OURLOG = { account:{handle:'{N}_official'}, posts:{1..6:{img:{right,wrong}, caption:{right,wrong}, comments:{right:[], wrong:[], half:[{at,who,text}]}, likes:{live:{right,half,wrong}, later:{right,half,wrong}}}} }`
  - 이 Task의 `posts`에는 **EP1만** 넣는다. EP2~6은 Task 2에서 더한다(빈 자리나 `TODO` 글을 넣지 않는다). verify는 Task 1에서 EP1만, Task 2에서 6편을 본다(아래 테스트의 `EPS` 상수).

- [ ] **Step 1: `test/verify.mjs`에 `[ourlog]` 절을 쓴다(실패하는 테스트)**

```js
console.log('[ourlog] 피드 계산·글 (docs/superpowers/specs/2026-11-20-ourlog-design.md)');
{
  const F = await import('../js/ourlog-feed.js');
  const { OURLOG } = await import('../data/ourlog.js');
  const EPS = [1];                                    // Task 2에서 [1,2,3,4,5,6]
  t('variantOf: full→right, half→half, none→wrong, null→null',
    F.variantOf('full') === 'right' && F.variantOf('half') === 'half' && F.variantOf('none') === 'wrong' && F.variantOf(null) === null);
  const p = OURLOG.posts[1];
  const half = F.commentsFor(p, 'half');
  t('commentsFor half: right에 끼워 넣고 원본은 그대로', half.length === p.comments.right.length + p.comments.half.length
    && p.comments.half.every(h => half[h.at].text === h.text) && F.commentsFor(p, 'right').length === p.comments.right.length);
  t('좋아요: 실시간은 오답이 더, 나중엔 오답이 덜(6편 배율)', EPS.every(i => {
    const L = OURLOG.posts[i].likes; return L.live.wrong > L.live.right && L.later.wrong < L.later.right; }));
  t('좋아요·팔로워: 정수, 📈와 같은 방향', [0, 20, 50, 100].every(f => Number.isInteger(F.followersFor(f)) && Number.isInteger(F.likesFor(p, 'wrong', f, 'live')))
    && F.followersFor(80) > F.followersFor(20) && F.likesFor(p, 'right', 80, 'later') > F.likesFor(p, 'right', 20, 'later')
    && F.likesFor(p, 'wrong', 50, 'live') > F.likesFor(p, 'right', 50, 'live') && F.likesFor(p, 'wrong', 50, 'later') < F.likesFor(p, 'right', 50, 'later'));
  t('fmtCount: 1,234 / 2.4만 / 8만', F.fmtCount(1234) === '1,234' && F.fmtCount(24000) === '2.4만' && F.fmtCount(80000) === '8만');
  const g = E.newGame(); g.badges = ['full', 'none', 'half', null, null, null];
  t('feedOf: 배지 있는 EP만, 최신 먼저', JSON.stringify(F.feedOf(g)) === JSON.stringify([{ ep: 3, variant: 'half' }, { ep: 2, variant: 'wrong' }, { ep: 1, variant: 'right' }]));
  t('imageKey: half는 right 그림', F.imageKey(p, 'half') === p.img.right);
  const lines = EPS.flatMap(i => ['right', 'wrong', 'half'].map(v => ({ i, v, list: F.commentsFor(OURLOG.posts[i], v) })));
  none('댓글: 편·갈래마다 8~10개(half는 끼운 뒤)', lines.filter(x => x.list.length < 8 || x.list.length > 10).map(x => ({ ep: x.i, who: x.v, text: String(x.list.length) })));
  none('댓글: 40자 이하, 유행어 없음, 이름 하드코딩 없음', lines.flatMap(x => x.list.map(c => ({ ep: x.i, who: c.who, text: c.text })))
    .filter(c => [...c.text].length > 40 || SLANG.some(s => c.text.includes(s)) || /솔|루나|SOL|LUNA/.test(c.text)));
  none('아이디: 영문 소문자 3~20자, 한 화면(half·wrong 목록) 안에서 겹치지 않음', EPS.flatMap(i => ['half', 'wrong'].flatMap(v => {
    const list = F.commentsFor(OURLOG.posts[i], v), ids = list.map(c => c.who);
    return list.filter((c, k) => !/^[a-z0-9_.]{3,20}$/.test(c.who) || ids.indexOf(c.who) !== k).map(c => ({ ep: i, who: c.who, text: v }));
  })));
  t('계정 = {N}_official 토큰', OURLOG.account.handle === '{N}_official');
}
```

`SLANG`·`none`은 `[말투]` 절 안에 있는 지역 상수다. 위 절을 `[말투]` 블록 안 끝에 두거나, 두 값을 파일 위쪽으로 끌어올린다(구현자 선택).
