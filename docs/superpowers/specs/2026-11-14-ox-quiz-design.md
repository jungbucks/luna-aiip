# 에피소드 확인 O/X 퀴즈 설계 (ROADMAP #4, 2026-11-14)

> 교사와 대화로 정함(2026-11-14). "교사 결정"은 교사가 말한 것, "AI 판단"은 설계자가 정한 것.

## 왜

- 교사: 저작권 같은 법 개념은 학생에게 굉장히 생소하다. 성인도 법 관련 이슈는 어려워한다. 에피소드 선택 한 번으로 끝내지 말고, **한 번이라도 더 눌러 보는 과정에서 개념을 습득**하게 하고 싶다.
- 지금은 에피소드마다 결정 한 번(오답 → 비유·교훈 팝업 → 재선택 또는 진행 / 정답 → 설명 팝업)으로 끝난다.

## 목표

1. 에피소드의 결정이 끝나면 **O/X 한 문제**. 방금 배운 개념을 **학생 생활에 가까운 다른 상황에 적용**하는 문제(교사 결정 — "그 에피소드에서 방금 겪은 상황을 다른 상황에 적용해 보게").
2. 맞히면 해설 → 다음으로. **틀리면 해설 → 같은 개념의 다른 상황 문제 하나 더**(교사 결정). 그것까지 틀리면 해설만 보고 넘어간다(AI 판단 — 무한 반복 없음).
3. **엔딩 리포트에 '다시 볼 개념'** — 두 문제 모두 틀린 에피소드의 개념을 모아 보여 준다(교사 결정). 점수·정답률 표시는 하지 않는다(AI 판단 — "점수 매기기"가 아니라 복습 목록).

## 하지 않는 것 / 실패로 보는 것

- **💰·📈·🛡 스탯, 배지, 엔딩 판정에 영향 없음**(교사 결정 — "ox로 돈 주는 건 아닌 것 같다"). ROADMAP #4의 "정답 시 💰+5"는 버린다. `js/engine.js`(규칙 단일 원천)는 건드리지 않는다.
- 법 개념을 틀리게 가르치거나 단정하면 실패 — SPEC §10 가드레일 그대로(저작권 "무조건 불법" 금지, 퍼블리시티권은 "법으로 보호받는 재산적 이익" 수준). 예외가 있는 개념(특허 공지 예외 등)은 해설에서 짚는다.
- 퀴즈가 늘어나 수업 시간이 크게 늘면 실패 — 에피소드당 30초~1분.
- 문항 수를 늘리는 것(로테이션·문제 은행)은 이번에 하지 않는다(AI 판단).

## 흐름 (AI 판단)

- 에피소드 결정이 끝나고 **월간 정산(`bridge()`) 직전**에 퀴즈. 지금 `bridge()`로 가는 길은 셋이다: 정답 팝업 [계속], 오답 [대가를 치르고 진행], 법정 씬(최종 아님) 뒤 계속. 세 길 모두 퀴즈를 거친다. **최종 법정(게임 오버로 엔딩)으로 가면 퀴즈 없음.** EP6은 퀴즈 → 엔딩.
- 한 에피소드의 퀴즈는 한 번만. 결과는 그 EP 퀴즈가 끝날 때 저장한다(저장 단계 값은 지금처럼 'ep', 새 단계 없음). 퀴즈 도중 새로 고치면 지금 이어 하기 규칙대로 그 EP 처음부터 다시 하고, 끝에 퀴즈가 다시 나와 결과를 덮어쓴다(AI 판단 — 기존 "이어 하기 = EP 시작 지점부터" 단순화를 따름).
- `G.quiz`는 `js/quiz.js`가 처음 기록할 때 만든다(`engine.newGame()`은 건드리지 않음 — AI 판단). 최종 법정으로 끝난 EP는 퀴즈를 안 풀었으므로 기록이 없고, 엔딩 목록에서도 빠진다.
- 화면: 기존 팝업(`js/ui/popup.js showPopup`) 재사용. 문제 팝업 = 제목 "개념 확인 O/X" + 권리 이모지·이름 + 문장 + 버튼 [⭕ 맞아요] [❌ 아니에요]. 결과 팝업 = "맞았어요!"/"아쉬워요" + 정답(O/X) + 해설 + 버튼(맞음 → [계속 →], 첫 문제 틀림 → [비슷한 문제 하나 더 →], 둘째도 틀림 → [계속 →]).
- 키보드: 기존 팝업의 초점·Enter 처리를 따른다(버튼 두 개에 첫 초점). 

## 데이터

- 새 파일 `data/quiz.js`: `export const QUIZ = { 1: { main: {q, a, exp}, more: {q, a, exp} }, … 6: … }` (`a` = true면 O). 이름 토큰(`{n}`)은 쓰지 않는다(학생 생활 상황이라 필요 없음).
- 진행 기록: 게임 상태 `G.quiz = { [ep]: 'ok' | 'more-ok' | 'missed' }`(첫 문제 맞음 / 둘째에서 맞음 / 둘 다 틀림). 저장 키·`schemaVersion` 그대로(필드 추가뿐 — 옛 저장은 `G.quiz` 없음 = 빈 기록, 엔딩 목록에서 빠짐).
- 퀴즈 판정·기록·'다시 볼 개념' 목록은 새 순수 모듈 `js/quiz.js`(DOM 없음, node 검산 가능). `main.js`는 흐름만.
- '다시 볼 개념' 한 줄 = 그 EP의 권리 이모지·이름 + **기존 `hint` 문장**(이미 개념 요약이고 검수된 문장 — 새 문장을 늘리지 않음). 없으면 그 칸을 숨긴다(다 맞혔다는 칭찬 문구도 넣지 않음 — 점수처럼 읽히지 않게, AI 판단).
